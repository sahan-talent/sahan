# Sahan Talent: Xirfad Kasta Hal Goob

**Every skill, one place.** Sahan Talent is a freelancing and job app built for Somalia. Businesses and individuals post vacancies and jobs, young Somalis apply and get hired, and everyone gets paid with the mobile money they already use: **EVC Plus** and **eDahab**.

## Why Sahan

Too many young Somalis finish school with real skills and no work to use them on. Freelancing platforms exist in other countries, but they don't support Somali payment methods, so local workers are left out. Sahan connects people who need work done with the young people ready to do it, and pays out through Somali mobile money.

## Features

- **Vacancies and jobs:** clients post full vacancies or one-off jobs
- **Search and filters:** popular, nearby and recommended jobs; part-time, full-time, remote
- **Jobs matched to you:** recommendations based on each profile
- **Application tracking:** apply in a few taps and follow every application
- **Chat and file sharing:** real-time one-to-one messaging
- **Ratings and reviews:** the best-rated freelancers rise to the top
- **Mobile money payments:** pay and get paid with a +252 number
- **Notifications:** new jobs, application updates, messages and payments
